Privacy Policy

App: gravityanti · Last updated: 14 November 2026

What this app is

gravityanti is a personal tool. Ahmet Bera Demir uses it on his own computer to work with his own Google account. It is not offered to the public and has no other users.

What it accesses

  • Google Sheets: to read and update Ahmet's own tracking spreadsheets.
  • Google Drive: only files this app creates.
  • Gmail: to prepare drafts and send emails only after Ahmet approves each one.

What it does not do

  • It does not sell, share or transfer Google user data to anyone.
  • It does not use Google user data for advertising.
  • Access keys are stored only on Ahmet's own computer.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Google Account → Third-party connections.

Contact

Through the project's GitHub page.
